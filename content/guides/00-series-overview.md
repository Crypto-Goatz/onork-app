0ncore.com is not a separate product from 0nMCP. 0ncore.com IS what happens when you use 0nMCP to build a business platform. Every feature on 0ncore.com was built using the same 1,554 tools across 96 services that every 0nMCP user gets access to.

## Two Paths, Same Destination

**Path A — 0nMCP (Developer)**
Install `npx 0nmcp`, connect to Claude Code or Cursor, describe what you want in plain English. The MCP server routes your commands to the right APIs. You build at the speed of conversation.

**Path B — 0ncore.com (No-Code)**
Sign up, get your token, use the dashboard. Visual automation builder, drag-and-drop workflows, one-click installs from the marketplace. Same engine underneath. No terminal required.

Every case study shows both paths.

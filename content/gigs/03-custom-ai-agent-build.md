## FAQ

**Q: Is this a chatbot?**
No. A chatbot answers questions. An agent takes actions. Ours does the latter — sends emails, books calendar events, updates CRM records, charges customers via Stripe. Real actions on your real data.

**Q: Will it hallucinate?**
We engineer against this with: (1) explicit tool definitions instead of free-form responses, (2) decision logic that requires actual data lookup before acting, (3) approval gates for irreversible actions (sending emails, charging cards). Day 1 accuracy is ~85%; after 30 days of tuning it's ~95%.

**Q: What if it does something wrong?**
Every action is logged. Most agents we build include "soft mode" toggles where the agent drafts the action but waits for approval. You can flip irreversible actions to approval-required only.

**Q: Can I add tools myself later?**
Yes. After delivery you have a 0nCore admin panel. Run `0nmcp add notion` (or any service), paste OAuth, the agent inherits it.

**Q: Where does my data go?**
Stays in your 0nCore account (Supabase). We don't have a copy. We can't see it after delivery.

**Q: What if my use case is way bigger than $497?**
Tell us in the discovery call. If it's a multi-agent orchestration, multi-team deployment, or requires custom training — we'll quote a higher tier ($1,997 - $9,997 range) and tell you exactly why before charging.

**Q: Will it work for non-technical users?**
The build is technical (we do it). The use is not. Once delivered, anyone in your team can chat with the agent through Slack / web / CRM. No engineers needed.
